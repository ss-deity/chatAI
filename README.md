# 🤖 ChatAI

> A modern AI Chat application built with Vue 3, TypeScript, and Vite.

ChatAI 是一个基于 **Vue 3** 构建的现代 AI 聊天应用，支持流式对话（SSE）、多模型接入，并通过 **AI Gateway** 统一访问 OpenAI Compatible API，旨在提供一个可扩展的 AI 应用开发基础框架。

---

## ✨ Features

- 💬 Chat conversation
- ⚡ Streaming response (SSE)
- 🤖 Multi-model support
- 🔄 Conversation management
- 🌙 Modern UI
- 📱 Responsive layout
- 🔐 Authentication (Coming Soon)
- 📎 File upload (Coming Soon)
- 📚 RAG (Coming Soon)
- 🤖 AI Agent (Coming Soon)

## 🚀 Getting Started

### Install

```bash

```

### Run

```bash
pnpm dev
```

### Build

```bash
pnpm build
```
